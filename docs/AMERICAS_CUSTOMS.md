# 北米・中南米・カリブの税表、追加税、手数料

以下の税表件数は、過去版のデータ同梱配布物における2026年11月12日の記録です。GitHub公開版からは公的照会先と通関案内を確認できます。

第4回の57仕向地を実装しました。2026年11月12日を指定した照会では、標準税表・品目別税率資料が**24仕向地**、追加関税や輸入税などの別表が**8仕向地**、通関・郵便・港湾の手数料資料が**9仕向地**にあります。別表のうち追加関税・貿易救済措置は5仕向地です。

公的資料で通関手続または税関領域を確認した仕向地は55件です。ブーベ島とベネズエラは公的な照会先を案内します。税表の一部や地域共通表のみを収録する仕向地では、品目番号・国別の例外・申告制度を確認してください。

## 税表と追加措置の照合

- 米国のHTS改訂第23版、カナダのT2026-2、メキシコのLIGIEを収録。米国の232条・301条・338条、カナダの米国原産品や鉄鋼に関する追加措置、メキシコの対象PVCのアンチダンピング税を別表で参照します。原産地、適用日、例外、併用可否、輸入禁止・許可を貨物ごとに確認します。 [米国国際貿易委員会の税表](https://www.usitc.gov/harmonized_tariff_information) ・ [米国CBPの338条案内](https://content.govdelivery.com/accounts/USDHSCBP/bulletins/430e931) ・ [カナダCBSAの追加税案内](https://www.cbsa-asfc.gc.ca/publications/cn-ad/cn26-23-eng.html)
- ブラジルのIPI、ジャマイカのGCT・物品税・環境賦課金などは通常関税と分けて照会します。エクアドルのクーリエ区分Bの資料は該当する特別制度を指定した照会で返します。
- プエルトリコは米国関税領域として域外からの輸入資料を照会できます。米国との相互方向は共通領域の扱いを確認します。米領ヴァージン諸島には現地制度を案内します。フランス領ギアナなど、関税とVATの領域が異なる方向も確認に回します。 [米国の関税領域](https://www.ecfr.gov/current/title-19/chapter-I/part-101/section-101.1) ・ [欧州委員会の関税・VAT領域表](https://taxation-customs.ec.europa.eu/taxation/vat/vat-directive/how-does-vat-work/territorial-scope_en)

## 手数料

| 仕向地 | 収録した参照条件 |
| --- | --- |
| 米国・プエルトリコ | FY2027の正式MPF、手入力加算、簡易申告の区分、課税郵便、指定急送施設、船舶のHMF |
| カナダ | Canada Postの課税郵便取扱料 |
| メキシコ | 連邦権利法第49条の一般区分DTAと下限 |
| アルゼンチン | 統計手数料の率、価額別上限の出典、原産地免除 |
| ブラジル | SiscomexのDI申告の基本額。明細追加やDUIMPは方式別に確認 |
| バハマ | 規則147のC13申告処理料。2026年7月1日施行の上限を収録 |
| バミューダ | 指定港・空港の荷役手数料。郵便その他の免除条件を確認 |
| ジャマイカ | CAFを確認するための当局資料。金額は申告区分ごとに照会 |

方向照会では `destinationFeeReferences`、通関計画では `feeReferences` を返します。通関計画は輸送方式に合う資料を表示します。申告区分や港、免除条件は担当者が確認し、注文見積もりには貨物単位で確認済みの費用根拠を使います。簡易申告の複数区分や、郵便事業者と税関の料金を重複計上しないようにしてください。 [米国CBPのFY2027手数料表](https://www.federalregister.gov/documents/2026/07/31/2026-15530/customs-user-fees-to-be-adjusted-for-inflation-in-fiscal-year-2027) ・ [バハマの2026年改正規則](https://laws.bahamas.gov.bs/cms/images/LEGISLATION/AMENDING/2026/2026-0057S/2026-0057S.pdf)

## 実行例

```sh
npm run cli -- worldwide-coverage 2026-11-12
npm run cli -- customs-plan examples/customs-plan-us.json
```

品目別の税率と追加措置は `POST /v1/tariffs/lookup` で、仕向地、原産地、品目番号、輸入日を指定します。実注文による通関・請求照合は第8回で検証します。 [世界全方向の開発計画](WORLDWIDE_ROLLOUT.md) ・ [OpenAPI](openapi.json)
