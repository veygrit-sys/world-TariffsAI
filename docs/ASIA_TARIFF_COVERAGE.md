## 残る仕向地の確認事項

収録には、品目番号、税率、適用日の3点を確認できる公的資料が必要です。仕向地により、当局の原本の取得、改正の統合、公式照会サービスでの個別確認を進めます。

## 実装と照会

- シンガポールは標準関税表と物品税表を別の参照として収録しました。マカオは自由港の通常関税と、許可・消費税を区別します。
- カザフスタンとキルギスはEAEUの共通対外税表を参照します。加盟地間の方向は貨物の税関上の地位・通過経路を確認する手続に回します。 [EAEU条約第25条](https://www.un.org/en/ga/sixth/70/docs/treaty_on_eeu.pdf)
- 品目による原産地条件、関税割当、従量税・複合税、追加関税、輸入VAT・GSTは各資料の収録範囲と貨物の事実を照合します。収録範囲外の金額は未確定です。

`npm run cli -- worldwide-coverage 2026-11-12` で第2回と世界全体の件数を確認できます。品目別照会は `POST /v1/tariffs/lookup` で輸入先・原産地・品目番号・輸入日を指定します。 [品目別税率データ](TARIFF_DATA.md) ・ [OpenAPI](openapi.json)
