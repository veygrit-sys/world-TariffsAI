# 中国本土・米国向け一般消費財の試験判定

注文時点の資料に基づくB2Cの事前確認。運送会社や通関業者の請求、正式な申告・税額決定は別途照合する。検証用の注文、証憑参照、買手、品目の審査結果はすべて架空。証憑の真偽や残枠は外部システムと照合していない。確認日と再確認期限は日本時間で2026年11月25日から12月2日まで。依頼日と輸入日がともにこの期間にある場合に適用する。

## 中国本土

| 入力または境界 | 判定 |
| --- | --- |
| 9610の直購または1210の保税在庫 | 個人使用、登録済みの申告主体と対象流通経路、ポジティブリストの条件、注文・決済・物流の署名済み電子データを確認する。 |
| 買手の本人確認 | 取引の実在性と購入者の本人情報を確認し、当局等の認証か、未認証の場合は購入者と支払者の一致を確認する。 |
| 購入前残枠と申告価格 | 人民元の小売代金、送料、保険料を合計し、確認済みの完税価格との一致を求める。確認済みの年間残枠を超える注文は一般貿易の審査へ回す。 |
| 完税価格が5,000元以下 | 年間残枠内の対象商品を通常の越境EC扱いとする。金額を返す品目は、試験で照合した陶製食器（中国8桁69120010、HS6桁691200）の単一明細に限定する。 |
| 5,000元超・26,000元未満、現物1個のみ | 年間残枠内なら越境EC経由での輸入候補となる。貨物の関税、輸入増値税、消費税を全額審査する。他の上限超過注文は一般貿易の審査へ回す。 |
| 陶製食器の輸入税 | 通常枠の関税は0元。品目の税区分、消費税対象外、徴収時点の証拠まで揃うと法定13%の70%を輸入増値税として計算する。分未満の端数が出る場合は丸めを保留する。 |

`cn.json` の合成注文では商品90.00元、送料10.00元、保険0.00元。試算結果は関税0.00元、消費税0.00元、輸入増値税9.10元となる。購入時の徴収は、この例の事業者資料に記録された条件である。通関・運送手数料を含む総額は未確定。

`recordRef` は注文を確認した社内記録の参照番号。個人情報を格納しない。`transactionAndBuyerAuthenticityReviewed` と `buyerIdentityBasis` は買手の真正性・確認根拠、`channelFilingConfirmed` は申告主体の登録と経路要件、`quotaBeforeOrderConfirmed` は直前残枠を扱う。`cnCommodityCode` は当該明細を確認済みの国内8桁番号。`nonExciseStandardVatConfirmed` と `importTaxCollection` は該当明細の税区分と購入者への徴収時点を扱う。

- 適用枠と課税価格は[財関税〔2018〕49号](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5202372/content.html)・[財関税〔2016〕18号](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5203746/content.html)。
- 電子データ、購入者と支払者、納税義務、申告通貨は[海関総署公告194号](https://www.mofcom.gov.cn/zfxxgk/gkml/art/2021/art_1e97a9dbe17b45398e962927596b16f9.html)・[商財発〔2018〕486号](https://www.mofcom.gov.cn/zfxxgk/gkml/art/2018/art_1e2248ade45e4652a12c25d6a45e4f28.html)。
- 主たる品目の根拠は[2019年版の対象品目表985行](https://gss.mof.gov.cn/gzdt/zhengcefabu/201912/P020191227607915178053.pdf)・[2022年改訂表](https://gss.mof.gov.cn/gzdt/zhengcefabu/202202/P020220221322524635155.pdf)。

## 米国

`network` は確認済みの国際郵便網または非郵便輸送。輸送手段の記載との一致を求める。通常の越境B2C商品について、800米ドル以下でも自動的な少額免税を適用しない。非郵便は、申告者による手続、HTSUS、追加関税等の確認へ回す。国際郵便では次の区分を使う。

| 条件 | 判定 |
| --- | --- |
| 2,500米ドル超、または恒常的な正式申告要件あり | 正式申告と個別例外を審査。法定割当・関税割当、AD/CVD、法令で略式対象外となる物品、指定酒類・たばこ等を確認する。 |
| 2,500米ドル以下、恒常的な除外条件なし、他省庁要件または対象となるHTSUS第98・99章・FTA措置あり | 遵守期限延期の対象範囲と申告者の体制を審査。Entry Type 13の試験利用には参加資格・手続の確認が必要。 |
| 2,500米ドル以下、双方の条件を確認して該当なし | 略式申告の候補。CBPの個別判断、申告者、分類、課税額は引き続き確認する。 |
| 申告要件を未確認 | 不明のまま審査へ回す。 |

`permanentFormalEntryTrigger` は恒常的な正式申告要件、`pgaChapterOrPreferenceTrigger` は19 CFR 145.12(a)(2)(v)・(vi)が定める具体的な要件を表す。いずれも証憑で確認した `present`・`absent` を受け付ける。未確認は値を省略する。米国の例は中国からの800米ドルの国際郵便で、後者に該当すると仮定した。どの判定でも税額と到着時の徴収総額は未確定。
