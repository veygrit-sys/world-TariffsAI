# 国別の関税・通関試算

対象は越境B2C注文。注文時の税、輸入時の税・公的手数料を元通貨で表示する。購入者への転嫁、運送会社の立替料、各国の全税目を含む最終額は未確定。各金額には一次資料IDが付き、回答に出典URL・再確認期限を記録する。部分試算の台帳上の扱いは保留。見本はすべて合成データ。

| 仕向地 | 今回の検証範囲 | 主な保留事項 |
| --- | --- | --- |
| EU27の通常関税地域 | 第三国からの低額通信販売。EUR建て、150ユーロ以下、H7の適格性・申告明細・識別子・定額関税適用を確認。申告1明細当たり関税3 EUR。Y126と申告者のF00が確認できれば別費目で2 EUR | VAT、手数料の購入者転嫁、H1、域内配送、特別地域、明細未確定。150 EUR超での取扱料の適用はこの機能の対象外 |
| 英国 | 英国本土3地域の直販、135 GBP以下。登録、販売・配送条件、SKU別税率を確認して購入時VATを計算 | 北アイルランド、混合税率、物流手数料 |
| シンガポール | 航空・郵便。登録販売者の品目単位の少額判定、未登録販売者の合算CIF判定。購入時と輸入時のGSTを区別 | 支払済み証跡の引継ぎ、許可・運送費用 |
| 豪州・ニュージーランド | 対象文房具1明細。居住消費者・海外販売者・配送条件・登録等の確認後、販売時GSTを試算 | 豪州は郵便に限定。NZの貨物賦課金の購入者転嫁は請求書で確認 |
| 中国本土 | 対象品目とCBECの本人・三単・枠・決済・原産等の条件を確認。対象陶製食器の増値税・関税等を区別 | 一般貿易、未確認の品目、年間残枠、代理徴収の証跡 |
| 米国 | 郵便と非郵便の手続き、明細・追加税・他省庁確認の要否 | 米国向けの自動免税・一律税額は扱わない |
| 日本 | 確認済み文房具3種の少額免税。通常地域、積出国・合算・除外品・CIFを確認、課税価格合計1万円以下 | 一般商品の日本向け通常輸入には既存の中国→日本単一明細の別機能がある。今回の少額試算では異なる評価法を保留 |

EU27は共通制度の適用先であり、各国の国内VATの実装数ではない。標準地域の確認は呼び出し元の責任。通貨と品目・申告条件が一致した範囲のみを使う。各提出明細は購入明細と重複なく対応させる。異なる商品説明・商品識別子は安全側に倒して統合を保留する。EUの申告者負担額を個人の追加支払額として表示しない。

## 実行

```sh
npm run build
npm run cli -- country-preview examples/country-pilot/fr.json 2026-11-25T00:00:00+09:00
npm run cli -- country-reconcile examples/country-pilot/gb-receipt.json 2026-11-25T00:00:00+09:00
npm run cli -- shadow-ledger examples/shadow-ledger-world.json --synthetic --site
```

SDKは `previewCountryShipment` と `reconcileCountryPreview`。HTTPは認証付き `POST /v1/worldwide/country-preview` と `POST /v1/worldwide/country-reconcile`。要求例は `examples/country-pilot/`。請求照合は原本の保存・真贋判定と独立した費目比較。決済時の証憑と輸入請求書を別々に比較する。資料の期限が過ぎた案件は再試算・新規請求を保留する。各国固有の条件は対応する国別ノートを参照。

## 次の実証

最初に日本発のシンガポール・英国・豪州向け文房具で、購入時の税明細と配送会社の到着時請求（請求なしの場合はその証跡）を同一注文に紐付ける。EUはドイツまたはフランスでH7の申告明細、F00の負担者、購入時VATを揃える。米国は申告種別と税番・追加税の適用記録を先に検証する。既存の中国→日本を含め、実績は方向別に集計し、保留や資料不足の注文も分母に含める。商用判定には独立した実請求照合と各ルートの審査が必要。

[欧州委員会の関税・取扱料ガイダンス](https://taxation-customs.ec.europa.eu/customs/eu-customs-reform_en) ・ [日本税関の少額免税案内](https://www.customs.go.jp/english/c-answer_e/imtsukan/1006_e.htm)
