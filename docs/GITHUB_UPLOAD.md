# GitHub公開版と追加データ

GitHub公開版には、API・CLI、連携例、公式資料の参照先と通関案内、テスト、空の品目別税表マニフェストが含まれます。クローン直後の検証は、`npm ci --ignore-scripts` と `npm run check:public` を実行します。GitHub Actionsも同じコマンドを使います。

## 追加データと履歴の検証

- 取得した公式原本、追加税表、審査候補や署名の秘密鍵は、アクセスを制御したリポジトリ外の場所で保管します。追加税表の承認には、該当する輸入日の根拠、利用条件、承認署名が必要です。 [税表の運用手順](TARIFF_UPDATE_OPERATIONS.md)
- 過去の検証資料は、対象バージョンのデータ同梱配布物で確認します。取得記録・受領証跡も、対象配布物の `qa/` と `candidates/` を参照します。
- rc.22の全テストを再現するには、検証専用にソースをコピーし、信頼できるrc.21配布物の `data/tariffs/` をコピーの同じ場所へ展開します。rc.22の出典台帳を使うため、`data/` 直下のファイルは公開版から取得します。検証専用コピーで `npm ci --ignore-scripts` と `npm run check` を実行します。実際の輸入に使う税表には、別途その取引の根拠確認と署名承認が必要です。

公開ブランチには設定例の `.env.example` を置きます。実際の設定、サービスキー、通関・取引の個人情報は、各運用環境で管理します。独自コードと第三者データの利用条件は、ライセンスと帰属情報を参照してください。 [LICENSE](../LICENSE) ・ [第三者の利用条件](../THIRD_PARTY_NOTICES.md)
