# HS分類候補の国・地域別データ（rc.27）

2026年11月18日に確認した公式資料を参照し、54か国・地域、47出典、131件の国別候補ルールを収録しています。HS6の種類は15件です。出典数には品目表だけでなく、HS版・公開元を裏付ける資料を含みます。同一のWCO資料は国別に重複計上していません。いずれも限定した商品仕様の候補案内で、国内細分・税率・輸入許可・申告承認の提供を示す件数ではありません。

## 資料ごとの制限

中国本土の出典は海関総署2025年第259号の内容を香港政府の公式再掲PDFで確認しました。GACC原サイトへの直接接続ができなかったためであり、香港向け分類へ置き換えていません。シャワー間仕切りでは金属枠が基本特性を与えるか、ガラス主体かを別の条件にしています。

米国はUSITC公式検索の索引本文でHS6の記載を確認しました。直接表示の一部はJavaScriptに依存するため、特定の最新改訂版や税率を確認したとは扱いません。カナダはCBSA T2026-2第69類、豪州はABFの現行第9類、ニュージーランドは2026年10月20日版の公式PDFを確認しています。

シンガポールは、現行の税関案内から参照されるHS2022 Product Guide（2022年6月版）を利用しています。酒類の分類が候補にあっても、許認可・年齢条件・物品税・輸送受付の適格性は別途確認します。

英国の条件には `customs_territory: great_britain` を要求します。北アイルランド向けにそのまま流用しません。コーヒーは現在の公式Trade Tariff APIを主な根拠とし、英国政府のHS2022資料は分類体系の照合にだけ使います。協定税率・原産地資格・協定の発効は判定しません。

韓国は2022年12月31日改正版、台湾は2023年（112年）版の輸入税則とHS2022の公開元を確認しています。2026年度の最新国内細分・税率を照合したとは扱いません。香港はHKHS2022と2026年品名リストを照合し、HKSITC2007と区別します。マカオは現行公式導線が指すPDFの本文で2022年・第7版を確認しています。URL末尾はHS2020ですが、本文はHS2022です。香港・マカオの資料は申告・統計品目分類の参照であり、関税率表や免税判定ではありません。

マレーシアは2022年関税令を廃止した2025年関税令の本文を確認しました。タイの英語分類表は資料自身が参考用としており、法的拘束力を認定しません。フィリピンは関税委員会の公式索引がリンクするAHTN2022第9類PDFを確認しています。Google Driveの保存先はその公式リンク先です。ベトナム・マレーシア・タイのHS2022原産地関連附属書は、品目記述と版の照合にだけ使い、協定の発効・原産地資格・特恵税率を判定しません。インドネシアは2022年の基本分類と現行BTKI2022案内を参照し、後続改正を統合した国内税表とは扱いません。

インドはDGFTのITC(HS)2022輸入政策付録Vで品目記述を確認しました。食品リスク区分や取扱港を分類条件へ流用しません。UAEはドバイ税関の公式税番対応表とHS2022移行ガイドを照合し、12桁への移行時期・国内細分・他のGCC加盟国への適用は確定しません。サウジアラビアはZATCAの実際のコーヒー区分を確認しています。

スイスは2025年3月版一般輸入品目表と2022年改訂案内、ノルウェーは2026年品目表、アイスランドは2026年適用のHS2022第3版を参照します。サウジアラビア・アイスランドのHS版を補足するWCO表は、表自体が法的効力・公式な適用認定を持たないことを明記しているため、体系の照合にだけ使います。

ブラジルは2026年11月11日版公式Excel、メキシコは2025年7月28日版参考統合PDFと2026年10月14日版公式コード一覧、南アフリカは2026年11月13日版公式PDFを照合しました。チリはHS2022導入官報の基礎分類に限定し、最新統合税表を確認したとは扱いません。Mercosur・SACU・スイスとの共通関税領域などを理由に、未確認国へ自動展開しません。

トルコの2026年公式税表では対象コードを確認できましたが、今回の調査ではHS版の裏付けが不足したため収録を見送りました。未収録は当該国がHS2022を採用していないことを意味しません。

すべての資料の確認日は2026年11月18日、新規カタログの内部確認範囲は同日から12月18日です。これは資料の法的有効期間ではありません。再確認期限・商品属性・国・輸出入区分・HS版が合わない場合は候補の利用を保留します。大容量PDFやExcelで検索ツールが本文を表示できない場合も、公式URLから取得して該当行・親項目・版を照合しています。原本全文は同梱しません。

## 使い方と検証

国・地域別の表に今回追加した19件の入力例をリンクしています。従来の[米国](../examples/classification-us.json)、[中国本土](../examples/classification-cn.json)、[シンガポール](../examples/classification-sg.json)、[英国](../examples/classification-gb.json)、[ドイツ](../examples/classification-eu-de.json)、[豪州](../examples/classification-au.json)の入力例も利用できます。

```sh
npm run cli -- classification-propose examples/classification-kr.json 2026-11-18T12:00:00+09:00
npm run cli -- classification-propose examples/classification-br.json 2026-11-18T12:00:00+09:00
```

`tests/classification-countries.test.ts` は全131ルールの完全入力と、必須属性の各欠落・各条件の矛盾を確認します。全54か国・地域について、輸出区分・異なるHS版・期限切れで候補が出ないことと、HS6参照だけからの国内税番の承認を拒否することを検証します。追加したルールの商品条件は、`tests/fixtures/classification-countries.json` とカタログで追跡できます。

このデータ追加でカタログのダイジェストは変わります。カタログ全体へ結合した承認記録は、実行時の設定と一致する版で再確認してください。独自カタログを環境設定で指定している場合、同梱カタログの追加がそのファイルへ自動混入することはありません。
