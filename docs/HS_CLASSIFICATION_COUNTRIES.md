# HS分類候補の国・地域別データ（rc.28）

2026年11月18日JST確認。138か国・地域、151出典、384件の国別ルール、33種類のHS6を収録しています。今回は84か国・地域、104出典、253ルールを追加しました。出典数には品目記述だけでなく、HS版・正式な共通法域・公開元を補足する資料を含み、同一URLの出典は重複計上していません。

全250仕向地の残作業は[展開台帳](HS_CLASSIFICATION_ROLLOUT.md)と[JSON](HS_CLASSIFICATION_ROLLOUT.json)へ記録しています。候補がある国も限定商品の参照段階であり、国内細分・税率・輸入許可・運用者承認・配送受付の完成を意味しません。

## 共通資料を使った範囲と例外

SIECAはGT/SV/HN/NI/CRの5国、UEMOAはBJ/BF/CI/GW/ML/NE/SN/TGの8国、SACUは既存ZAにBW/LS/NA/SZの4国、EACは今回KE/RW/BI/TZ/UGの5国、EAEUはAM/BY/KZ/KG/RUの5国について正式な表・版・採用範囲を確認しました。LIはスイス関税法域の正式根拠を併用します。単なる加盟や政治的な所属から未確認国へ流用しません。

EUのボーンチャイナ皿と未充填クッション用シェルの2例は、EU27と、関税適用を個別確認したAX/GF/GP/MQ/RE/YT/MF/MCへ共通条件を維持して展開しています。ADはHS25〜97類の関税同盟、SMは対象の非ECSC品の共通関税表採用を根拠とします。PRは米関税領域とHTSUS適用を確認し、既存US2例を展開します。MFとSXは区別し、VAT・物品税・免税・独立裁定の拘束力を推定しません。

新規地域の多くは純コーヒー豆の090111/090121/090122を収録します。MAは未焙煎090111/090112、TNは090111と包装3kg以下の非粉砕焙煎豆090121、UAは未焙煎090111/090112に限定します。BOは焙煎豆090121・殻付き乾燥ブラジルナッツ080121・生鮮マンゴー080450の3例であり、全新規国を同一のコーヒー3例とは扱いません。

## 資料の制限と継続作業

公式検索索引だけで本文を確認した箇所（MA/TNや既存US等）、参考用英訳、基礎版、原産地・輸出還付関連附属書、統計品目表は、その範囲に限定して使用します。協定の発効・原産地資格・還付資格・現行国内税率を示す根拠にはしません。WCO実施状況表も非拘束の補足照合に限定します。資料別の取得方法・ページ・保留理由は[今回の調査記録](HS_CLASSIFICATION_RESEARCH_RC28.md)に残しています。

HK/MOは申告・統計分類と関税率表を区別します。GBはGreat Britain属性を必要とし、北アイルランドへ流用しません。GCC/SACU/EAC/Mercosur等の未確認国を共通表の存在だけで追加しません。共有出典を統合しても、各国の採用を裏付ける補助sourceIdsは維持しています。

カタログのダイジェストが変わると旧版に結合した承認は再確認が必要です。独自カタログを設定している場合、同梱の追加データがそのファイルへ自動混入することはありません。

```sh
npm run cli -- classification-propose examples/classification-ca-610910.json 2026-11-18T12:00:00+09:00
npm run classification:rollout -- --date 2026-11-18 --write
```

全ルールの正例、各必須属性の欠落、各条件の矛盾、国・輸出入区分・HS版・期限の違い、HS6参照だけからの国内税番承認拒否を継続テストします。
