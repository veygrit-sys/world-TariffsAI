基準日 2026-11-18、確認日 2026-11-18。カタログ `2026-11-18.classification-v4`、ダイジェスト `c26323e56a0e07101abf97a27d85f2802556dd2ec0765ac3fbb21a459b76e253`。

ISOの249仕向地と補助地域コソボ（XK）を含む250件を追跡します。分類調査の対象は248件（取引の受付可否は別途確認）、限定商品の候補ありは138件、出典再確認は0件、公式分類の確認待ちは110件、商用対象外は2件です。

候補がある国も商品全体を網羅していません。照会先リンクの存在・加盟国一覧・共通のHS6だけでは分類確認済みにしません。国内細分、税率、原産地資格、取引の適格性、配送受付、運用者の承認はそれぞれ別に確認します。

## 分割して進める作業

| 段階 | 作業 | 完了条件 |
| --- | --- | --- |
| 1 | 国・地域別の公式分類根拠 | 本文・HS版・適用地域を照合し、商品属性と保留条件を記録 |
| 2 | 商品群と仕様境界 | 各章の実用品を追加し、材料・加工・用途・複合品・組物等の違いを検証 |
| 3 | 国内細分・税表版・確認済み割当 | 日付の合う国内税番と税表出典、商品仕様、記録された承認を結合 |
| 4 | 輸出区分と国際取引 | 輸入用の国内税番を流用せず、輸出分類と原産地・経由・各規制を別に検証 |
| 5 | EC接続と継続運用 | 商品台帳接続、通関計画への引継ぎ、取消・期限切れ・根拠改訂を実運用で検証 |

各段階は国・商品群ごとに進めます。後続段階が未完了の国を一括で完成扱いにしません。

## 再開・更新

```sh
npm run classification:rollout -- --date 2026-11-18
npm run classification:rollout -- --date 2026-11-18 --write
npm run cli -- classification-rollout 2026-11-18
```

`GET /v1/classification/rollout` はサービス認証のもとで同じ台帳を返します。`market`、`status`、`country`、`date`、`direction`、`hsEdition`、`offset`、`limit`で分割できます。集計は全台帳、`total`と`nextOffset`は絞り込んだページに対応します。

カタログ追加後はこのファイルとJSONを生成し直します。日時を再現する場合は`--now`にISO時刻を指定します。JSONの出典照会リンクは分類の根拠へ自動昇格しません。
