# 輸入時費用の請求照合

`reconcileInvoice` は、注文に保存した見積もりと通関後に記録した請求額を、同一通貨の最小単位で費目別に比較します。対象は関税、輸入VAT・GST、追加関税、物品税、通関費、運送会社の輸入時手数料です。購入代金と購入時に精算した送料は、それぞれの決済記録で確認します。

見積もりには6費目の各1行を保存します。金額未確定の見積もりは `null` を保持します。請求に同じ費目が複数行ある場合は、同一請求・同一通貨の明細を集約して渡します。0と確認できた費目には `"0"` を渡し、確認できていない費目は省略します。分類できない請求額は `other` として渡します。

請求と見積もりの `orderId`、`estimateId`、通貨が一致し、請求日が見積日以降であることを確認します。`difference` は請求額から見積額を引いた金額です。

請求側の `explanation` に、確認した差額理由の `reason` と根拠記録の内部ID `evidenceId` を指定できます。理由には関税率、課税価格、為替、税務上の扱い、手数料、端数処理、その他を指定できます。照合結果では、差額がある費目または見積額が未確定・対象外の請求費目に理由と内部IDを返します。

| 結果 | 条件 |
|---|---|
| `matched` | 比較対象の全費目が揃い、費目ごとに一致した |
| `differences` | 比較対象の全費目が揃い、いずれかの費目で差額が出た |
| `needs_review` | 未確定・欠落・見積もりに対応しない費目がある |

比較対象に未確定の費目があれば、その側の合計は `null` です。片側だけで確定した合計は利用できます。各識別子には注文・見積もり・請求の内部IDを使い、照合結果と原本の対応を注文記録に保存します。
