# 日中米の税表更新から通関明細照合まで

以下は過去版のデータ同梱配布物を使用した検証記録です。再現には該当する原本または試験データが必要です。

その他の仕向地の試験は [追加11仕向地の試験](WORLDWIDE_CYCLE.md) を参照してください。

2026年11月13日を輸入日にした日中米6方向の隔離試験です。各輸入国の公式原本を取得し、1税番の通常関税を審査候補に取り込みます。試験用の一時鍵で候補を承認し、実際のWooCommerceの未払い試験注文に見積もりを表示します。注文から読み戻した見積もりを、別に作成した合成通関明細と照合します。

| 輸入先 | 試験の税番 | 参照した通常関税 |
| --- | --- | --- |
| 日本 | 691390000 | WTO欄、2026年10月31日版第69類 |
| 中国 | 69120010 | MFN欄、2026年税表856ページ |
| 米国 | 6912001000 | Column 1 General、2026年改訂23版 |

米国版の原本取得時点は米国現地11月12日です。試験上の輸入日は11月13日です。税番と原産地は試験用に確定した値を使い、通常関税以外の費用、注文と通関明細は合成データで検証します。日本の通常関税と標準輸入消費税の試験値は、別途日本税関の原本と計算例に照合しています。実取引では追加関税、手数料、原産地特例、適用日を注文ごとに確認します。

## 再実行

Node.jsの依存を入れ、試験用の作業ディレクトリを用意します。元の実行と同じ税表原本で再現する場合は、取得記録のURLとSHA-256を照合してください。公式原本取得のコマンドは当日の取得記録を作成します。後日この試験を再現する場合は、収録済みの取得記録を使い、同じ原本をSHA-256で保管し直します。公式ファイルの更新後は、試験に使う税率と原本を再審査します。

```sh
npm ci
npm run tariff:acquire -- --sources JP,CN,US --output ./cycle-evidence
npm run tariff:pilot-cycle -- --official-evidence ./cycle-evidence \
  --report ./cycle-report.json --checkout-cases ./cycle-orders.json
```

`--official-evidence` を省略すると、通信と税率を合成したオフラインの回帰試験を実行します。いずれも、承認前・対象日外・切り戻し後の見積もり保留、明細差額、明細欠落、別見積もりの拒否を確認します。

続けて [WooCommerceの隔離実行手順](../integrations/woocommerce/README.md) で、上記の `cycle-orders.json` をWordPress Playgroundに渡します。出力を `woo-report.json` として保存し、次のコマンドで注文から読み戻した見積もりを照合します。発行済み見積もりは、同じ注文の表示が確認中に変わった後も、見積もりIDで読み戻せます。

```sh
npm run tariff:pilot-cycle -- --checkout-cases ./cycle-orders.json \
  --reconcile-woocommerce ./woo-report.json --report ./reconciled.json
```

試験結果は `qa/` に収録しています。商用の承認と実績の照合には、担当者の署名、店舗の対象注文、通関業者の明細を用意します。
