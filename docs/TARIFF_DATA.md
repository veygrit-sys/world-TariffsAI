# 品目別税率データ

GitHub公開版の [マニフェスト](../data/tariffs/manifest.json) は空です。税表と付加税の追加版は、対象国・地域、税関領域、版、参照可能日、取得ファイルのSHA-256、利用条件をそれぞれのマニフェストに記録します。 [追加データの運用手順](TARIFF_UPDATE_OPERATIONS.md)

以下の収録履歴は、過去版のデータ同梱配布物で確認した範囲です。

## 照会

```bash
npm run build
npm run cli -- tariff examples/tariff-ca-surtax.json
npm run cli -- tariff-coverage
```

`POST /v1/tariffs/lookup` には仕向地とHSコードを渡します。`originCountry` は原産国、`date` は輸入日の指定に使います。`/v1/ask` に `destinationCountry` と `tariffCode` を渡すと、同じ照会結果が `tariffReference` に付きます。

```json
{
  "destinationCountry": "CA",
  "originCountry": "US",
  "code": "0402.10.10.00",
  "date": "2026-11-11"
}
```

`matches` は基本税表の行です。HS6では国内細分を候補として返します。税表選択は `snapshotId` で指定でき、`offset` と `limit` でページを移動できます。特別領域は `zone: "special"` と `customsTerritory` を指定します。

`measures.matches` は輸入VAT・GST、追加関税、物品税、貿易救済措置などの候補です。`measureOffset` と `measureLimit` でページを移動します。各行の `snapshotId` を `measures.sources` の収録版と参照日に結び付けてください。

| 付加税の照合結果 | 内容                                                   |
| ---------------- | ------------------------------------------------------ |
| `exact`          | 同じ番号の付加税データ                                 |
| `prefix`         | 出典が指定する章・項・号など、入力番号の上位にある規定 |
| `more_specific`  | 入力した上位番号に属する国内細分の候補                 |

対象原産国は `originCountries`、明示された除外国は `excludedOriginCountries` で絞り込みます。素材の加工国は、商品の原産国と別の条件として `condition` に記載します。用途、材質、価格、事業者、原産地証明、割当、重複適用の制限は `condition` と原資料で確認します。候補の `expression` は出典の税率・算式です。単純な百分率は `adValoremPercent` にも入り、複合税・従量税・免税区分は算式や表記を参照します。

| 参照状態               | 確認事項                             |
| ---------------------- | ------------------------------------ |
| `source_not_loaded`    | 仕向地・領域に対応するデータの追加   |
| `date_not_covered`     | 輸入日に対応する収録版の追加         |
| `code_not_found`       | 品目番号と税則版の照合               |
| `rate_not_reported`    | 原表の税率欄と適用日                 |
| `no_matching_measures` | 収録範囲、品目番号、原産国、個別規定 |
| `territory_unresolved` | 税関領域の指定                       |

`date` を省略すると、各収録版の参照日が使われます。`compiled_reference` は韓国税関の参考集で、輸入日に適用する各国の正本は現地税関・法令で確認します。ECの照会には予定輸入日を渡し、各データの参照日と適用条件を表示してください。`applicableRate` は照会時点で未確定のため `null` です。税額概算は `/v1/assess` の確認済み計算ルールで行います。

## データ追加と再生成

税表マニフェストの収録版メタデータから `file`、`sha256`、`statistics` を除いた構造で `source.json` を作成します。`inputFiles` には取得元とSHA-256を記録します。`scope` は `national_schedule`、`published_baseline`、`compiled_reference`、`hs6_aggregate` です。付加税のデータには `role: "measures"` を設定します。

`lines.json` に先頭のゼロを含む品目番号を文字列で記録し、`rates` に税種、原表の式、期間、条件を入れます。付加税で上位番号の全配下を照会対象とする根拠がある行には `matchPrefix: true` を設定できます。対象原産国が資料に明記されている場合は `originCountries`、除外国が明記されている場合は `excludedOriginCountries` を指定します。

```bash
npm run tariff:import -- source.json lines.json ./private-tariffs
VEYGRIT_TARIFF_DIR=./private-tariffs/new-edition \
VEYGRIT_TARIFF_APPROVAL=./private-tariffs/approval.json \
VEYGRIT_TARIFF_TRUSTED_KEYS=/secure/tariff-reviewer-public-keys.json \
npm run cli -- tariff-coverage
```

`VEYGRIT_TARIFF_DIR` の複数パスはNode.jsの `path.delimiter` で連結できます。契約・許諾済みのデータは候補として検証し、署名承認した構成を内部配布で読み込みます。 [税表の取得・署名承認](TARIFF_UPDATE_OPERATIONS.md)

- [WTO Tariff & Trade Dataの利用条件](https://ttd.wto.org/download-static/terms-of-use)
- [UNCTAD TRAINSの利用条件](https://wits.worldbank.org/data/public/UNCTAD_TermsofUseandDisclaimer.pdf)

同じ版の元資料を保存し、マニフェストのファイル名とハッシュを照合します。ABFの章別HTMLは `raw-extra/au/` に保存し、`chapters.tsv` にURLとファイル名をタブ区切りで並べます。韓国税関の外国税表集はダウンロード時の `kr-world.xlsx` 名で配置します。配布ファイルの実体は国別XLSXを含むZIPです。再生成にはPython、`lxml`、`openpyxl`、Popplerが必要です。

```bash
pdftotext -bbox-layout raw/cn-2026.pdf raw/cn-2026-bbox.html
pdftotext -bbox-layout raw/eu-2026.pdf raw/eu-2026-bbox.html
npm install --prefix .tariff-tools --ignore-scripts mdb-reader@3.2.0
node scripts/tariffs/export-ca.mjs raw/ca-2026-2.accdb raw/ca-2026-2.json
python3 scripts/tariffs/rebuild.py raw private-tariffs/rebuilt
python3 scripts/tariffs/expand.py raw-extra raw private-tariffs/rebuilt
npm run data:check
```

日本の章別HTMLは `raw/jp-chapters/` に置き、実行関税率表の `inputFiles` を `files.json` に記録します。カナダのACCDBは公式ZIP内のファイルを使います。日次更新するCusModの再生成には当日の保存版を使います。収録資料の版が変わるときは抽出条件・参照可能日・ハッシュを更新し、照会結果を原資料と照合します。
